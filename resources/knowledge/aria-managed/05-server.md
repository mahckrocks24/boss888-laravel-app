# Your server

## Where can I see our server?
Open **Server** in the portal. It shows whether your server is online, its uptime for each of the last 30 days, the last backup and the last restore test, security (secure connection, automatic updates, firewall, sign-in protection), how much memory and storage is in use, and any incidents in the last 90 days.

## What do the yellow bars on the uptime chart mean?
Each bar on the **Server** page is one day. Green means your website answered every check that day; yellow means at least one of the checks (every 5 minutes) did not get an answer for a short time. Any incident is listed under **Incidents** with how long it lasted.

## Is our server shared with other customers?
It is your dedicated hosting environment, run and looked after by LevelUpGrowth. Capacity, backups and security for it are on the **Server** page.

## How do I get a file, page or record restored?
On the **Server** page choose **Request a restore**, or call or write to LevelUpGrowth support. Say what you need and from when; we restore it from your nightly backups.

## Can we restart or change the server ourselves?
No, and on purpose. Your server is run by LevelUpGrowth, so there are no server controls in the portal. If something needs doing, contact support.
