## 9-11. CONTRACT / POLICY / CANONICAL URL
Narrow action = `article_share`, authorised ONLY by an ArticleShareToken (HMAC-SHA256 over
workspace_id + article_id + platform + social_account_id + canonical_url + idempotency_key, keyed
by APP_KEY, 24h TTL). Verification requires every signed claim to EQUAL the live call, so a genuine
token cannot be replayed onto another article/workspace/account. Generic social actions stay denied.
Canonical URL: websites.custom_domain (only when domain_verified=1) > subdomain > refuse. Rejects
non-https, bare IP, staging/localhost hosts, /app /admin /api /preview /draft paths, non-/blog/ routes.
**Bug found via live data:** websites.subdomain sometimes holds a FULL host
('platform.levelupgrowth.io'); blind appending produced '...levelupgrowth.io.levelupgrowth.io'. Fixed.

## 12-13. CAPTION + PLATFORM RULES
Grounding is ENFORCED, not requested: any number/percentage or quoted phrase not present in the
article REJECTS the generated caption and falls back deterministically to title+excerpt+link.
Out-of-scope vocabulary (newsletter/email campaign/drip/ad campaign) also rejects. Deterministic
fallback always available. Supported: facebook, linkedin (dry-run payload shapes implemented).
Explicitly refused: instagram (cannot carry a link in-feed), twitter/x (no credentials configured)
— refused outright rather than creating an undeliverable draft.

## 14-17. TENANCY / APPROVAL / SCHEDULE / IMMEDIATE

execution. Immediate and scheduled both re-validate, mint the token, pass the kernel, then dry-run.

## 18-21. PROVIDER / IDEMPOTENCY / RETRY / NOTIFY
DryRunSocialConnector has NO HTTP client at all — verifiable by inspection. Idempotency key =
sha256(ws|article|account|platform|slot|nonce), UNIQUE-indexed; replay returns the original record

classified transient (timeout/5xx/rate-limit/network) vs permanent (credentials, revoked, deleted
article, cross-workspace, malformed URL) — permanent never retries and notifies the user.
